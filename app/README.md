## Langkah - langkah cara menjalankan aplikasi:
1. Clone repositori yang sudah saya buat:
git clone https://github.com/rofikassidiqqi17/TugasPengembanganAplikasiMobile2.git .
2. Buka aplikasi Android Studio kemudian pilih menu "OPEN" dan arahkan ke folder proyek yang sudah dibuat ini.
3. Tunggu hingga proses "Gradle Sync" nya selesai secara otomatis.
4. Pilih emulator (AVD) atau hubungkan perangkat Android fisik (USB Debugging aktif), Kemudian ketika sudah di hubungkan menggunakan kabel USB, klik tombol RUN atau segitiga berwarna hijau, di toolbar atas  atau tekan shortcut 'Shift + 10'.
5. Aplikasi akan otomatis kebuka.
